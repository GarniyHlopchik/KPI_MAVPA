# Обраний домен: сайт-форум

## Вимоги

-Можливість будь-яким користувачем створювати незалежну гілку для обговорень. Автор гілки може її закрити (не дозволяти нові публікації) або повністю видалити. 
-Модератори форуму можуть видаляти повідомлення, назавжди чи тимчасово банити користувачів за порушення
-Анонімні користувачі можуть відправляти повідомлення в гілки без реєстрації (виводиться як Anonymous) або можуть вказувати інформацію "на місці" з можливістю tripcode-ів. Наприклад, при введенні у поле імені користувача "John Titor#elpsykongroo", де символи після # є паролем, у повідомленні висвітиться tripcode, що є хешем вказаного пароля і доводить ідентичність користувача. 
-Статус реєстрації автора повідомлення є видимим у цьому повідомленні: зелений колір позначає, що повідомлення відправлене повноцінно зареєстрованим користувачем; жовтий колір позначає, що користувач не зареєстрований, але має tripcode у своєму імені; червоний позначає, що користувач має неперевірений юзернейм (або Anonymous)
-Користувачі можуть обмінюватись особистими повідомленнями. Вони є недоступними для модераторів. Також приватні повідомлення можуть існувати лише між зареєстрованими користувачами.
